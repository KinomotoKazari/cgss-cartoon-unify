# Included license texts

This folder keeps the license text that must travel with bundled third-party runtime code and adapted source material.

| File | Component | Why it is here |
|---|---|---|
| [AssetStudio-MIT.txt](AssetStudio-MIT.txt) | AssetStudio source reference and the adapted shared TypeTree string table | AssetStudio is MIT licensed. We keep its notice with the adapted table. |
| [CGSS-Resource-Tool-MIT.txt](CGSS-Resource-Tool-MIT.txt) | CGSS Resource Tool and `spine_preview` historical acknowledgement | CGSS Resource Tool is MIT licensed. Its notice is retained with the acknowledgement. |
| [MDUI-MIT.txt](MDUI-MIT.txt) | MDUI interface-design reference | MDUI is MIT licensed. Its notice records the design reference. |
| [Spine-3.6.txt](Spine-3.6.txt) | Bundled Spine 3.6 core and canvas runtime | The Spine runtime license requires the terms to accompany source or binary redistribution. |

The project does not bundle AssetStudio binaries. The CGSS-specific WebGL renderer and skeleton parser came from the supplied CGSS preview source, which did not include a separate license notice. Their provenance is recorded in [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md).

We leave the license texts themselves unchanged. See the project README for a short credit list and the third-party notice for file-level detail.
